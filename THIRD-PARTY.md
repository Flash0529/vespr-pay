Skills fetched on request (not part of this repository, not redistributed): when a person picks a field at first run and the room approves, the agent downloads one `SKILL.md` per entry at a fixed commit from the author's public repository and writes it into that workspace (`agents/src/packs.js`). Their licences were read from the repositories on 2026-10-28; each is shown to the room on the approval card before anything is downloaded. rea is instructions for the REA tool server; VESPR agents cannot call that server yet, and the card says so. Each file copied from rea's `references/` folder starts with a comment naming its source and licence.

Skills found with "Something else" in the first-run dialog are not listed here: they are chosen at run time (`agents/src/skillsearch.js`), only from repositories with an MIT, Apache-2.0, BSD-2-Clause, BSD-3-Clause, ISC, Unlicense or CC0-1.0 licence, and the card shows each one's licence, repository and commit before anything is installed.

Added 2026-10-29: the CodeMirror, Lezer and esbuild rows. The licence of each of the 29 packages that ended up in `app/vendor/editor.js` (and of esbuild) was read from its installed package metadata and its LICENSE file; `scripts/editor-licences.mjs` re-checks this on every build and fails if anything bundled is not MIT, Apache-2.0, BSD or ISC.
