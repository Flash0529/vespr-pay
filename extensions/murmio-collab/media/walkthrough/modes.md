## The team decides what agents may do

Use the **Agents** menu in the panel:

- **Manual**: ask before every edit and every command
- **Accept edits**: edits go through, commands ask
- **Auto**: only risky commands ask
- **Plan**: read-only until the team approves the plan
- **Bypass**: no prompts (sandbox only)

When an agent asks, an **Approve / Deny** card appears for everyone. The first answer decides, and everyone sees who gave it.
