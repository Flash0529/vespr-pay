# Try VESPR in three minutes

You are one of two people in this workspace (judge1 and judge2 are two logins of the same room). An AI agent, `coder`, is the third teammate. The agent runs on NVIDIA Nemotron through Nebius Token Factory.

1. Open the **VESPR** icon in the left bar. That is the team chat: everyone sees it, including what the agent does.
2. Type `@coder run python3 -m unittest -q`. The agent asks the whole room for approval; press **Approve**. The tests fail (that is the demo).
3. Type `@coder fix the discount bug in cart.py and run the tests again`. Watch the agent's cursor edit `cart.py` live; hover a line to see who wrote it and why.
4. Press **Ctrl+Alt+M then M** (**Cmd+Alt+M then M** on a Mac) for the **Code Map**: files, imports, symbols, and who wrote what.
5. Open the second login (the other link) in another browser window: you now see both of you, with named cursors, in the same file. Try typing in the same file.
6. Try `@coder start the project` after adding an `index.html`: the agent starts it and posts a preview link.

Limits you should know: this is a shared demo room, so everything you type is visible to the other judge; the AI has a daily token budget and says so when it runs out; the room can be reset at any time.
