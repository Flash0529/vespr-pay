Share

Anyone with the link joins as a guest, live, until it ends or you turn it off. They see every file in the project (a single file is shared as read-only text).

An edit link is a seat in the room, like a teammate's: whoever has it can change files, answer an agent's Approve or Deny card (including a request to run something), change the room's mode and write in the chat. Only give it to people you trust, and end it when you are done.

Links you made

Anyone with the link can read a copy made right now. It does not update, nobody can change it, and you can end it at any time.
