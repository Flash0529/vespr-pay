# Contributing

Thanks for helping. Two things first.

1. **Licence.** Contributions are accepted under the project's licence, the GNU AGPL v3 (`LICENSE`).
2. **Relicensing grant.** So the project can also be offered under commercial terms (see `NOTICE.md`), by sending a pull request you confirm that (a) you wrote it or have the right to submit it, and (b) you grant the project's copyright holders a perpetual, worldwide, non-exclusive licence to use, modify and relicense your contribution, including under proprietary terms. Add `Signed-off-by: Your Name <you@example.com>` to each commit (`git commit -s`) to confirm this.

Run the tests before you send a change: `./scripts/test-all.sh` (no keys needed). Never commit secrets, tokens or keys; a scan runs before anything is published.
